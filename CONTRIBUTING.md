# Contributing

The repository is private and is not currently offered under an open-source license. Invitations do not imply copyright transfer, sublicensing rights or permission to redistribute any existing artwork.

Contributors working on the renderer may receive **read access** to approved assets without access to the entire private `virgo-stars` repository. Visual assets are different from source code: the owner must confirm original authorship, assignment, explicit permission or a compatible license **for each selected asset or defensible asset family**.

Use a focused branch + PR. Describe files, source, license/rights evidence, SHA-256 and impact on VirgoStars and the Astrolabio. Avoid image replacements without side-by-side visual regression tests. Do not add GitHub Actions or automated deploys.

For a proposed new asset, create or update the rights review records first. Never classify unreviewed upstream inventory data as distributable solely because it exists in a private repo or on a public website.

Run `npm test` for import helper scripts. An integration test on real chart images requires separately approved access to the asset pack.
