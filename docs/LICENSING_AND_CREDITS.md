## Images and other non-code resources

**The software license is not blanket permission for images.** The project owner has affirmed personal authorship of the 1,013 images (see [owner-authored artwork](OWNER_AUTHORSHIP_AND_ARTWORK.md)). The existing `public/assets/` image files are approved for private collaborators under `catalog/approvals.json`, not for public redistribution. `catalog/publication-approvals.json` is an intentionally empty, separate public rights register until the rights holder reviews each image.

On 2026-11-12, the project owner selected **CC BY 4.0** for their own original artistic contributions. See [artwork licensing policy](ARTWORK_LICENSING_POLICY.md). This owner-level choice does not independently establish third-party rights or clear each image for distribution. Original composition and lawful rights in underlying fonts, glyphs, textures, maps and other sources require separate scrutiny. Third-party material keeps its own license; no right can be granted here if the rights holder does not possess it.

For a new public record, identify the exact asset path and SHA-256, author/rights holder, chosen license SPDX identifier, explicit public reuse/redistribution authorization and a reference to third-party/font clearance. Only add such records with genuine owner approval.

## Why this distinction matters

**This repository was made public on 2026-11-12.** Its accessible Git history may already have been cloned or cached. Deleting an asset in a later commit does not revoke previously available copies or settle any pre-existing rights issue. Continue the historical content audit and per-file clearance, and escalate any questionable material promptly.

Read [the release checklist](PUBLIC_RELEASE_CHECKLIST.md) and [rights review](RIGHTS_AND_REVIEW.md) before distribution. This guide is informational; the exact license and the actual rights documentation govern.
